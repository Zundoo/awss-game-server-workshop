# 4.8.1. Quản lý Mã nguồn trên GitHub Repository

*   **Mục tiêu**: Lưu trữ toàn bộ mã nguồn ứng dụng Game Server WebSocket, file thiết kế Dockerfile và file cấu hình tự động hóa luồng lên kho lưu trữ trực tuyến an toàn.
*   **Thao tác thực hiện**:
    1. Khởi tạo một kho chứa mã nguồn công khai (Public) hoặc riêng tư (Private) trên tài khoản GitHub của sinh viên đặt tên là `aws-game-server`.
    2. Đẩy toàn bộ mã nguồn hiện tại lên nhánh chính `master` (hoặc `main`).
