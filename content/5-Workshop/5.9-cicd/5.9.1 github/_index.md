# 4.8.1. Source Code Versioning via GitHub Repository

*   **Objective**: Manage and house the WebSocket Game Server source files, Dockerfile manifests, and automation workflow definitions securely on a remote cloud repository.
*   **Implementation Steps**:
    1. Initialize a repository on the student's GitHub profile, named `aws-game-server`.
    2. Push the baseline source code directory up to the primary development branch (`master` or `main`).
