# 4.2.1. Initializing Amazon ECR Repository

*   **Objective**: Create an Amazon Elastic Container Registry (ECR) Private Repository to manage and version the containerized Game Server builds securely.
*   **Step-by-Step Implementation**:
    1. Search for and navigate to **Elastic Container Registry (ECR)** on the AWS Console.
    2. Click the **Create repository** button.
    3. Configure parameters:
        * **Visibility settings**: Select **Private**.
        * **Repository name**: Input `game-server`.
    4. Click **Create repository**.
