# Nhật ký học tập - Tuần 7

### Mục tiêu Tuần 7:
* Tìm hiểu phương pháp Quản lý hạ tầng bằng mã lệnh (Infrastructure as Code - IaC).
* Tìm hiểu dịch vụ tự động hóa hạ tầng AWS CloudFormation.
* Ôn tập các kiến thức nền tảng về Docker và dịch vụ điều phối Amazon ECS.
* Tìm hiểu quy trình tự động hóa tích hợp và triển khai liên tục (CI/CD) sử dụng AWS CodePipeline.

### Các kết quả đạt được trong Tuần 7:
* **Tiếp cận tư duy hạ tầng dạng mã lệnh (IaC):** Hiểu rõ tầm quan trọng và phương thức ứng dụng tự động hóa mã lệnh để thay thế hoàn toàn cho các hoạt động click chuột cấu hình thủ công.
* **Làm chủ công cụ AWS CloudFormation:** Nắm vững cấu trúc viết file Template và quản lý Stack, giúp tăng tốc độ tái lập môi trường hệ thống một cách chính xác.
* **Củng cố vững chắc kiến thức Containerization:** Khắc sâu quy trình quản lý Docker và vận hành kiến trúc phân phối container tự động trên bảng điều khiển Amazon ECS.
* **Xây dựng nền tảng tư duy DevOps:** Hiểu rõ bản chất luồng chạy của một đường ống dẫn CI/CD tự động thông qua dịch vụ AWS CodePipeline, nâng cao năng lực triển khai phần mềm chuẩn quy trình.
